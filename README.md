# Task Master Pro

Prosta, ale “produkcyjna” aplikacja do zarządzania zadaniami zbudowana w **Next.js (App Router)** + **TypeScript** + **Tailwind CSS**. Projekt służy jako ćwiczenie nowoczesnego Reacta: `useReducer`, Context, custom hooks, derived state i dobre praktyki.

## Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- ESLint

## Funkcje (MVP)
- Dodawanie zadań z priorytetem (low/medium/high)
- Oznaczanie jako wykonane
- Usuwanie zadań
- (Planned) Filtry: all / active / completed
- (Planned) Persistencja w `localStorage`

## Wymagania
- Node.js >= 18

## Start lokalnie

```bash
npm install
npm run dev
